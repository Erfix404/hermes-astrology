# 🔍 موارد نیازمند تأیید بصری (Vision Cross-Check)

**هدف:** لیست داده‌هایی که از متن/prose استخراج شدن ولی منبع اصلی‌شون جدول عکسیه.
هر آیتم رو با مدل ویژن روی PDF مربوطه چک کن و نتیجه رو کنارش بنویس.

- **فایل:** `book/Houlding_ptolemy_terms.pdf` — صفحات ۳۴–۳۸، نوارهای جدول عکس هستن

## ۲. Speculum مقادیر Drishti — BPHS صفحات ۲۱۰-۲۱۲
- **فایل:** `book/bphs_san.pdf` — جدول کامپیوتری زاویه→ویروپا (صفحه ۲۱۱ PDF)
- **وضعیت:** فرمول piecewise پیاده شد (Rules 1-6)؛ subagent چند خطای OCR توی جدول پیدا کرد (مثلاً 31:30→0.15 که باید 0.75 باشه). اگه ویژن داشتی: چند ردیف تصادفی رو با فرمول بسنج.
