# واژه‌نامه تخصصی و اصطلاحات نجومی (Glossary)

این واژه‌نامه مرجع استاندارد برای ترجمه و یکسان‌سازی اصطلاحات در خروجی‌های فارسی AI Agent است.

## ۱. ارکان چارت و محاسبات
| انگلیسی | اصطلاح فارسی | توضیح کوتاه |
|---|---|---|
| Ascendant / Rising | طالع / برج طالع | برجی که در افق شرقی در لحظه تولد بالا می‌آمده است |
| Midheaven (MC) | وسط‌السماء / قله چارت | بالاترین نقطه جنوبی مدار در لحظه تولد (حوزه شغل/شهرت) |
| Descendant (DC) | غارب / افق غربی | نقطه روبروی طالع (خانه هفتم / روابط) |
| Imum Coeli (IC) | وتدالارض / انتهای آسمان | پایین‌ترین نقطه چارت (خانه چهارم / ریشه‌ها/خانواده) |
| Natal Chart | زایچه / چارت تولد | نقشه آسمان در لحظه تولد فرد |
| Synastry | تطبیق چارت‌ها / مقایسه سینستری | بررسی جنبه‌های بین دو چارت برای سنجش سازگاری |
| Composite Chart | چارت کامپوزیت (نقاط میانی) | چارت هویت مشترک رابطه بر اساس نقاط میانی سیارات |
| Whole Sign Houses | سیستم خانه‌های مساوی برجی | هر برج کامل یک خانه است (سنتی) |
| Placidus | سیستم پلاسیدوس | سیستم خانه‌بندی زمانی مبتنی بر تقاطع زمانی |

## ۲. سیارات و نقاط فرضی
| انگلیسی | فارسی | دلالت کلیدی |
|---|---|---|
| Sun | خورشید / شمس | اراده، هویت خودآگاه، پدر، رهبری |
| Moon | ماه / قمر | عواطف، ذهن ناخودآگاه، مادر، امنیت روانی |
| Mercury | عطارد / تیر | ذهن، تفکر، بیان، مهارت، تجارت |
| Venus | زهره / ناهید | عشق، ارزش‌ها، هنر، کشش، هماهنگی |
| Mars | مریخ / بهرام | انرژی خام، اقدام، شجاعت، خشم، میل |
| Jupiter | مشتری / برجیس | انبساط، خرد، شانس، ایمان، رشد |
| Saturn | زحل / کیوان | انضباط، ساختار، آزمون، مسئولیت، کارما |
| Uranus | اورانوس | دگرگونی ناگهانی، نوآوری، بیداری، آزادی |
| Neptune | نپتون | الهام، تخیل، حل‌شدگی، معنویت، ابهام |
| Pluto | پلوتو | دگرگونی بنیادین، مرگ و تولد دوباره، قدرت |
| North Node (Rahu) | گره شمالی / رأس | مسیر رشد روحی، افق ناآشنا، جاه‌طلبی |
| South Node (Ketu) | گره جنوبی / ذنب | ریشه‌های کارمایی، استعداد گذشته، وابستگی‌های رهاشدنی |
| Chiron | کایرون / زخم شفابخش | عمیق‌ترین زخم که به بزرگترین موهبت تبدیل می‌شود |
| Part of Fortune | سهم‌السعاده / لوت بخت | نقطه تقاطع خورشید، ماه و طالع؛ رفاه طبیعی |
| Lot of Spirit | سهم‌الغیب / لوت روان | نقطه جهت‌گیری اهداف و کارنامه زندگی |

## ۳. جنبه‌ها (Aspects)
| انگلیسی | زاویه | فارسی | ماهیت |
|---|---|---|---|
| Conjunction | ۰° | قران | یکی‌شدن و ادغام انرژی‌ها |
| Sextile | ۶۰° | تسدیس | فرصت ملایم و همکاری نیازمند تلاش |
| Square | ۹۰° | تربیع | تنش، اصطکاک و موتور رشد و چالش |
| Trine | ۱۲۰° | تثلیث | جریان طبیعی، استعداد روان و آسانی |
| Opposition | ۱۸۰° | مقابله | رویارویی، تقابل و آگاهی از طریق دیگری |
| Quincunx / Inconjunct | ۱۵۰° | تعدیل ناخوشایند | ناهماهنگی بین دو انگیزه ناهمگون |

## ۴. احوال کواکب و کرامه‌ها (Dignities)
| انگلیسی | فارسی | حالت |
|---|---|---|
| Domicile / Rulership | بیت / حاکمیت | سیاره در خانه خود و با بیشترین قدرت عمل می‌کند |
| Exaltation | شرف | سیاره در اوج درخشش و افتخار قرار دارد |
| Detriment | وبال | سیاره در نقطه مقابل خانه خود در فشار و محدودیت است |
| Fall | هبوط | سیاره در نقطه مقابل شرف احساس تضعیف یا افت می‌کند |
| Peregrine | غریب | سیاره فاقد شرافت اساسی در آن درجه است |
| Retrograde | راجع / رجعت | حرکت ظاهری معکوس؛ بازنگری درونی انرژی |

## ۵. روش‌های پیشگویی و زمان‌بندی (Timing Systems)
| انگلیسی | فارسی | توضیح |
|---|---|---|
| Transits | ترانزیت‌ها / عبورها | تأثیر حرکات جاری آسمان بر زایچه |
| Secondary Progressions | پراگرسیون‌های ثانویه | هر روز پس از تولد برابر با یک سال زندگی |
| Solar Arc Directions | دایرکشن‌های قوس خورشیدی | جابجایی ۱ درجه در سال برای همه سیارات |
| Annual Profections | پروفکشن سالانه | فعال شدن خانه‌ها به ترتیب سن از طالع |
| Firdaria | فردار / فکردار | دوره‌های بلندمدت سیاره‌ای بر اساس روز/شب |
| Zodiacal Releasing (ZR) | رهایش برجی | زمان‌بندی فصول اوج شغلی/جسمی از لوت‌ها |
| Loosing of the Bond (LOB) | گسست پیوند | نقطه عطف و پرش به برج مقابل در دوره‌های برجی |
| Vimshottari Dasha | داشای ویمشوتاری | چرخه ۱۲۰ ساله سیاره‌ای ودیک بر اساس ماه تولد |
| Gochara | گوچارا | ترانزیت‌های ودیک از ماه تولد (شامل سده‌ساتی) |
| Ingress | اینگرس / ورود | لحظه دقیق ورود خورشید به یک برج (آغاز فصل/سال) |
